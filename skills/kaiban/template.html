How sessions keep this page current
  1. The state lives in this page's database, not its HTML. Sessions read and write it with the ArtifactData tool on this page's URL; nobody republishes the page to update it.
  2. A session keeps its row in sessions current: what it's doing now, its state, when it last checked in.
  3. Handing off is moving a card to the next stage: its stage, the stage's session as owner, state: "handed", from and handedAt. Dragging a card into a session's column does exactly that. A message to the other session is a nudge; the card is the record.
  4. Picking up sets state: "doing" and pickedUpAt. Until then the card says "not picked up".
  5. Asking you adds a needs doc with options and actFor, the session that acts on the answer. It closes the ask and logs it once it has acted.
  6. Done moves the card to stage: "done" and adds a log row with links.
